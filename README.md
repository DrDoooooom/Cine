# Cine

Cine is a React Native application that allows users to search for movies and view information. It leverages the TMDB (The Movie Database) API to fetch real-time movie data.

## How it Works

- Built with **React Native** for cross-platform mobile support  
- Integrates with the **TMDB API** to fetch movie titles, posters, overviews, ratings, and more  
- Users can **Search** movies by name and **view full details** on selection  

## Requirements

- Node.js
- React Native CLI
- TMDB API Key
